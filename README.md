# Starters

This is a collection of tested patterns, blueprints, recipes, you name it... for various service,s frameworks and tools to get started and expand on more quickly. Each one has a testsuite and can be used with Docker. Installation commands are leaned toward brew on macOS, but should be easy to modify.

## Content

In alphabetical order:

- [aws-apprunner](https://github.com/deeplook/starters/tree/main/aws-apprunner): A fairly minimal AWS AppRunner example with a NodeJS Docker container in AWS ECR.
- [aws-ec2](https://github.com/deeplook/starters/tree/main/aws-ec2): A minimal, tested AWS EC2 instance running a vanilla Nginx server.
- [aws-ecs-fargate](https://github.com/deeplook/starters/tree/main/aws-ecs-fargate): An AWS ECS cluster.
- [fastapi-basic](https://github.com/deeplook/starters/tree/main/fastapi-basic): A minimal, tested FastAPI server implementing most HTTP methods.
- Hexagonal architecture, more to come...
- Twelve factor application, more to come...
