# Starters

This is a collection of tested building blocks for various frameworks and tools to get started and expand on more quickly. Each one has a testsuite and can be used with Docker.

## Content

- [aws-apprunner](https://github.com/deeplook/starters/tree/main/aws-apprunner): A minimal, tested AWS AppRunner example with a NodeJS Docker container in AWS ECR, managed with Terraform.
- [aws-ec2](https://github.com/deeplook/starters/tree/main/aws-ec2): A minimal, tested AWS EC2 instance managed with Terraform.
- [aws-ecs-fargate](https://github.com/deeplook/starters/tree/main/aws-ecs-fargate): An AWS ECS cluster managed with Terraform.
- [fasstapi-basic](https://github.com/deeplook/starters/tree/main/fastapi-basic): A minimal, tested FastAPI server implementing all HTTP methods.
